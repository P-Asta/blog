# hello RUST

폴더를 초기화했다면 `src/main.rs`에 이런 코드가 있을겁니다.

간단하게 `println!`안에있는 내용물을 바꾸고 출력해볼까요?

```rs {3}
// main.rs
fn main() {
  println!("hello Rust!");
}
```

`cargo r`을 사용하여 실행!
